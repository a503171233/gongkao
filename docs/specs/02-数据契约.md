# 02 · 数据契约（REST/SSE/数据模型/环境变量）

> 版本：v1.0 · 依据现有 `api.py`/`auth.py`/`chat.py`/`store.py`/`config.py` 实测签名整理
> 本文件是**跨模块唯一真源**。任何接口/字段/模型的增删改，必须先改这里并经统筹确认。

---

## 1. 通用约定

- **Base URL**：对外 `http://YOUR_SERVER_IP:3000/api`；内网后端 `:9000`（路由不含 `/api`）。
- **路由前缀**：nginx `/api/` 反代会剥掉 `/api`（尾斜杠），故后端路由实为 `/ask`、`/auth/gitee/*`，对外带 `/api`。
- **鉴权头**：`Authorization: Bearer <token>`（登录用户计额度；缺失视匿名，不限额）。
- **上传鉴权**：`X-Upload-Secret: <UPLOAD_SECRET>`（配置了 `UPLOAD_SECRET` 时必填，否则 403）。
- **编码**：所有 JSON `ensure_ascii=False`；SSE 为 `text/event-stream`。
- **多老师参数**：涉及知识库/问答的接口带 `teacher_id`（默认 `T001`）。

## 2. 数据模型

### 2.1 用户体系（`auth.db`）

**表 `users`**

| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | TEXT PK | uuid hex[:16] |
| username | TEXT UNIQUE | 登录名（OAuth 用户为 `昵称@gitee`） |
| password_hash | TEXT | `salt_hex$hash_hex`（PBKDF2-HMAC-SHA256, 16B salt, 120k 迭代） |
| role | TEXT | `free` / `member` |
| today_count | INTEGER | 今日已用次数 |
| quota_date | TEXT | `YYYY-MM-DD`，跨天重置 |
| created_at | TEXT | UTC 时间 |

**表 `oauth_links`**：`(provider, provider_uid)` 联合主键 + `user_id` + `created_at`

**额度**：`FREE_DAILY=20`、`MEMBER_DAILY=200`。

### 2.2 会话体系（`chat.db`）

**表 `sessions`**：`id PK`、`session_id UNIQUE`、`user_id`、`teacher_id`、`created_at`、`last_active_at`

**表 `messages`**：`id PK`、`session_id`、`role`（`user`/`assistant`）、`content`、`created_at`

**历史注入上限**：`HISTORY_LIMIT=10` 轮（api.py 取 `limit=HISTORY_LIMIT*2` 条消息）。

### 2.3 知识库（Chroma）

- collection 名：`teacher_{teacher_id}`，`hnsw:space=cosine`
- 块元数据：`teacher_id`、`doc_name`、`idx`
- 块 id：`{doc_name}_{idx}_{md5(content)[:8]}`
- 分块：`chunk_size=600`、`chunk_overlap=120`（可被老师配置覆盖）

## 3. REST 接口清单

### 3.1 健康与老师

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| GET | `/health` | — | `{status, teachers:[teacher_id,...]}` |
| GET | `/teachers` | — | `{teachers:[{teacher_id,teacher_name,teacher_subject}]}` |
| GET | `/info` | `teacher_id=T001` | `{teacher_id,teacher_name,teacher_subject,llm_model,embed_model,embed_provider,chunk_count}` |

### 3.2 账号与额度

| 方法 | 路径 | 请求体/参数 | 返回 |
|---|---|---|---|
| POST | `/register` | `{username,password}` | `{token,user_id,username,role}`；400 用户名重复/密码<6 |
| POST | `/login` | `{username,password}` | `{token,user_id,username,role,quota_left}`；401 错误 |
| GET | `/me` | Header Authorization | `{anonymous:false,username,role,quota_left}` 或 `{anonymous:true}` |

### 3.3 Gitee OAuth

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/auth/gitee/status` | `{enabled:bool,name:"Gitee"}` |
| GET | `/auth/gitee/login` | 307 跳授权页；未配置 503 |
| GET | `/auth/gitee/callback?code=&state=` | 302 回首页 `/?token=xxx`；state 无效 400；失败 502 |

### 3.4 问答与会话

| 方法 | 路径 | 请求体/参数 | 返回 |
|---|---|---|---|
| POST | `/ask` | `{query,teacher_id="T001",stream=false,session_id=""}` | 非流式 dict / 流式 SSE（见 §4） |
| GET | `/sessions` | `user_id="anonymous"` | `{sessions:[{session_id,teacher_id,created_at,last_active_at,message_count}]}` |
| GET | `/sessions/{id}/messages` | — | `{session_id,teacher_id,messages:[{role,content,created_at}]}`；404 |
| DELETE | `/sessions/{id}` | — | `{deleted:session_id}` |

### 3.5 知识库管理

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| POST | `/upload` | `teacher_id` + `X-Upload-Secret` Header + `file` | `{filename,teacher_id,chunks,stored,total}`；403 无权限；400 入库失败 |
| GET | `/documents` | `teacher_id=T001` | `{teacher_id,documents:[{doc_name,chunks,teacher_id}]}` |
| DELETE | `/documents/{doc_name}` | `teacher_id=T001` | `{deleted,remaining}` |

### 3.6 监控与守卫

| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/guard/stats` | `{total,by_teacher,by_reason}` |
| GET | `/metrics` | 见 §5 metrics.snapshot |
| GET | `/metrics/prometheus` | Prometheus 文本（`gk_*`） |

## 4. SSE 事件协议（`POST /ask?stream=true`）

| 事件 | data 负载 | 说明 |
|---|---|---|
| `start` | `{request_id,teacher_id,session_id}` | 流开始 |
| `delta` | `{text}` | 增量文本片段 |
| `refs` | `{references:[{doc_name,score}],session_id}` | 引用列表（含会话 id） |
| `done` | `{session_id}` | 正常结束 |
| `guard_block` | `{fails:[...],reason}` | 幻觉拦截（前端替换已显示文本为拒答提示） |
| `error` | `{message}` | 中途异常 |

**非流式 `/ask` 返回结构**：

```json
{
  "request_id": "...", "teacher_id": "T001", "session_id": "...",
  "answer": "...", "rejected": false,
  "references": [{"doc_name":"...","score":0.95}],
  "guard_fails": []
}
```

## 6. 稳定函数契约（模块内跨文件，不得漂移）

### 6.2 `answer.py::ask`（B4 调度）

```
ask(query, teacher_id="T001", stream=False, history=None)
  非流式 → dict{answer, hits, rejected[, mock, guard_fails]}

```

### 6.3 `guard.py::run_guard`（B8）

```
run_guard(answer, hits, tcfg, teacher_id) -> (passed:bool, detail:{fails:[...],checked:[...]})

```

### 6.4 `chat.py::ChatStore` 关键方法

## 7. 环境变量（`Config`，`config.py`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `API_BASE_URL` | `https://ai.anyyds.cn/v1` | LLM 中转站 |
| `API_KEY` | 空 | 中转站 key（必填，否则 ask 报错） |
| `LLM_MODEL` | `gpt-5.6-luna` | 默认模型（老师可覆盖） |
| `EMBED_PROVIDER` | `local` | `local`/`api`/`selftest` |
| `EMBED_MODEL` | `BAAI/bge-small-zh-v1.5` | 本地 embedding 模型 |
| `UPLOAD_SECRET` | 空 | 空=不鉴权；设置后 `/upload` 必带 |
| `DB_PATH` | `data/vector` | Chroma 持久化目录 |
| `DATA_DIR` | `data` | 原始课件目录 |
| `MODEL_CACHE` | `data/models` | fastembed 模型缓存 |
| `AUTH_DB` | `data/auth.db` | 账号库（compose 钉死 `/data/auth.db`） |
| `CHAT_DB` | `data/chat.db` | 会话库（compose 钉死 `/data/chat.db`） |
| `GITEE_CLIENT_ID/SECRET` | 空 | Gitee OAuth（未配置时优雅降级） |
| `TEACHER_ID/NAME/SUBJECT` | T001 | 旧 CLI 默认老师（兼容） |
| `CHUNK_SIZE/OVERLAP` | 600/120 | 分块参数 |
| `TOP_N` | 6 | 默认召回数 |
| `SIMILARITY_THRESHOLD` | 0.5 | 默认相似度阈值 |
| `TEMPERATURE` | 0.3 | 默认温度 |

## 8. 契约变更流程（统筹管理）

1. 模块开发者发现需要新增/修改字段、接口 → 在对应模块说明书中标注「契约变更提案」。
2. 统筹复核 → 更新本 `02-数据契约.md` → 广播受影响模块（给出影响面）。
3. **未定稿前不得据此开发**，避免 A/B 系列串味漂移。
