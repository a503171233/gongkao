# B2 · 知识库管理模块（网站二 内核）

## 1. 目标

课件入库全链路：文本提取（md/txt/docx/pptx/pdf）→ 清洗 → 分块 → 写入向量库；提供文档列表、删除、清库；知识库变更时失效检索缓存。

## 2. 现状

- `backend/poc/ingest.py`：`extract_text` / `clean_text` / `chunk_text` / `ingest_file`、`Chunk` 数据类。
- `backend/poc/store.py` 写入侧：`upsert_chunks` / `list_documents` / `delete_document` / `clear_collection`。

## 3. 函数契约（`02` §6.1）

| 函数 | 返回 | 说明 |
|---|---|---|
| `ingest_file(path, cfg)` | `list[Chunk]` | 解析为分块（含 doc_name/idx） |
| `upsert_chunks(chunks, teacher_id)` | `int` | 写入并失效该师检索缓存 |
| `list_documents(teacher_id)` | `list[dict]` | 按 doc_name 聚合 chunk 数 |
| `delete_document(teacher_id, doc_name)` | `int` | 删指定文档全部块 + 失效缓存 |
| `clear_collection(teacher_id)` | `None` | 清空整个 collection |

## 4. 功能点清单

1. 多格式解析：md/txt 直读 UTF-8；docx 用 python-docx（段落）；pptx 用 python-pptx（shape 文本）；pdf 用 pymupdf（`page.get_text`）。
2. 清洗：`\r`→`\n`、去空行、strip。
3. 分块：段落自然边界聚合，`chunk_size=600`/`overlap=120`；单段超长硬切。
4. 入库：chunk id=`{doc_name}_{idx}_{md5[:8]}`，元数据 `{teacher_id,doc_name,idx}`，幂等 upsert。
5. 缓存失效：任何写入/删除调用 `retrieve_cache.invalidate_prefix(f"retr|{teacher_id}|")`。

## 5. 允许修改文件

- `backend/poc/ingest.py`
- `backend/poc/store.py` 中「写入/删除/列表」相关函数（检索函数归 B3，勿动签名）

## 6. 验收标准

- [ ] 5 种格式文件均能提取到可见文本
- [ ] 分块数、id、元数据正确；重复入库幂等（块数不翻倍）
- [ ] 删除文档后 `list_documents` 无该项且缓存已失效（紧接检索能命中新结果）
- [ ] 空文件/不支持格式抛明确异常（不静默入库）

## 7. 坑与注意事项

- 新增解析格式需同步检查 `requirements.txt` 是否已含依赖（docx/pptx/pdf 已含）。
- 解析失败须抛 `ValueError("入库失败: ...")`，由 B1 转 400。
- `doc_name` 用文件名精确匹配，删除时注意大小写/扩展名一致性。
