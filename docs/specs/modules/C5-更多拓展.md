### 7.2 安全加固行为变更（需知悉）

1. `/upload` 现在**拒绝白名单外扩展名**（400）与空文件（400），文件名含路径段被清洗为纯文件名（防穿越）——此前可上传任意文件名。
2. `/login`、`/register` 同 IP 5 分钟内超过 10 次 → 429（此前无限制）。nginx 层 3r/m 上传限流保持。
3. 状态变更请求（POST/PUT/DELETE/PATCH）带 `Origin` 头且与 Host 不同源、不在 `CSRF_ALLOWED_ORIGINS` → 403。**无 Origin（curl/服务端）放行**，Bearer 鉴权语义不变。
4. `/me/logout` 吊销当前 token 后立即失效（重启不丢）；`/me/logout-all` 当前仅吊销当前 token（全量吊销需 token 版本化改造，已注明）。
