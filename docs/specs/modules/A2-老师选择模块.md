# A2 · 老师选择模块（网站一 前端）

## 1. 目标

拉取并渲染老师列表，支持学员切换老师；展示当前老师信息（名称/科目/知识库规模/模型）；老师切换会重置当前会话并通知 A5 刷新。

## 2. 现状

`frontend/index.html` 老师 tab/下拉，基于 `/teachers` 渲染，默认 T001，切换后所有 ask 带对应 `teacher_id`。

## 3. 接口依赖（`02-数据契约.md` §3.1）

| 接口 | 用途 |
|---|---|
| `GET /api/teachers` | 老师列表 `[{teacher_id,teacher_name,teacher_subject}]` |
| `GET /api/info?teacher_id=` | 单老师详情（含 `chunk_count`） |

## 4. 功能点清单

1. 初始化：拉 `/teachers`，渲染老师选项；默认选中 T001（可从 `GK.store.teacherId` 继承）。
2. 切换：更新 `GK.store.teacherId`，拉 `/info` 展示当前老师知识库块数，广播 `teacher:changed`。
3. 空列表兜底：拉取失败时保留默认老师，展示错误提示而非白屏。
4. 联动：切换老师触发 A3 新建会话（旧会话归档），A5 清空渲染区。

## 5. 模块内契约

- **文件**：`frontend/js/a2-teacher.js`。
- **共享状态**：`GK.store.teacherId`（默认 `T001`），变化后 `GK.bus.dispatchEvent(new CustomEvent('teacher:changed', {detail:{teacherId}}))`。
- **依赖 A4**：走 `GK.api()` 拉数据（不自己 fetch）。

## 6. 允许修改文件

- `frontend/js/a2-teacher.js`（新建）
- `frontend/index.html` 老师选择区容器

## 7. 验收标准

- [ ] 老师列表正确渲染且默认 T001
- [ ] 切换老师后后续 ask 的 `teacher_id` 正确（在 A4 日志/网络面板确认）
- [ ] 切换老师触发会话重置与渲染区清空，无残留旧老师内容
- [ ] `/info` 展示 `chunk_count` 正常

## 8. 坑与注意事项

- `teacher_id` 必须严格用注册表值（`T001`/`T002`），前端不得自行编造。
- A2 不负责会话的创建逻辑（交 A3），只发 `teacher:changed` 事件。
