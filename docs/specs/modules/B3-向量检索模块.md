# B3 · 向量检索模块（网站二 内核）

## 1. 目标

Chroma 向量库封装 + embedding 适配（local/api/selftest 三模式）+ 语义检索（查询变体扩充 → 召回 → 合并去重取高分）+ 检索缓存。

## 2. 现状

`backend/poc/store.py` 检索侧：`embed_texts` / `_query_variants` / `retrieve` / `collection_count` / `list_collections` / `_collection`。

## 3. 函数契约（`02` §6.1）

| 函数 | 返回 |
|---|---|
| `retrieve(query, teacher_id, top_n=None)` | `list[dict]`（`id/content/meta/score`） |
| `embed_texts(texts)` | `list[list[float]]` |
| `collection_count(teacher_id)` | `int` |
| `list_collections()` | `list[str]` |

## 4. 功能点清单

1. 多老师隔离：collection=`teacher_{teacher_id}`，cosine 空间；历史 L2 空间自动删除重建（需重 ingest）。
2. Embedding 三模式：`local`=fastembed（懒加载单例，threads=2）、`api`=中转站 OpenAI embeddings、`selftest`=离线哈希（仅自测）。
3. 查询变体：原句 / 去引号主干 / 引号内短语 / 去疑问助词，去重保序，上限 4。
4. 召回合并：多变体 query 多向量一次查询，按 chunk id 合并取最高相似度 `score = max(0, 1-distance)`，排序取 top_n。
5. 检索缓存：TTL 5min，键 `retr|{teacher_id}|{query}|{top_n}`（`_safe_key`），命中直接返回。
6. 边界：空库返回 `[]`；召回上限不超过集合现有块数（防 `NotEnoughElementsException`）。

## 5. 允许修改文件

- `backend/poc/store.py`（检索/embedding/缓存相关；写入侧由 B2 负责，勿动）

## 6. 验收标准

- [ ] `retrieve` 返回带 `score` 的命中列表，且 teacher 间互不串库
- [ ] 三种 embedding 模式可切换且结果维度正确（selftest 仅自测）
- [ ] 查询变体提升召回：含引号短语的问题能命中对应片段（黄金集命中率不下降）
- [ ] 知识库变更后检索缓存已失效（新块立即可搜）

## 7. 坑与注意事项

- 本地 embedding 首次拉模型需 `HF_HUB_DISABLE_XET=1` + `HF_ENDPOINT=https://hf-mirror.com`。
- `threads=2` 针对 2 核服务器，勿擅自调大线程。
- `score` 阈值过滤在 B4（answer）层做，B3 只返回原始 score，不在这里阈值过滤。

### 8.1 改动摘要（共 6 处，全部在检索侧白名单内）

| # | 函数 | 类型 | 根因与说明 |
|---|---|---|---|
| 1 | `_get_fastembed` | 加固 | api.py 同步路由跑线程池，并发首载存在**双重加载 ONNX 模型**风险（2C/3.6G 服务器真实威胁）→ 加 `threading.Lock()` 双检锁。`threads=2` 保持不变 |

| 3 | `retrieve` | 修复 | 读路径原经 `_collection()` 的 `get_or_create` **创建空 collection**（打错 teacher_id 留垃圾库）→ 新增 `_collection_exists()` 只读探测，不存在直接返回 `[]`。已核 5 个调用方（answer/api/guard/golden/self_test）无依赖此副作用 |
| 4 | `retrieve` | 微优化 | `coll.count()` 由 2 次合并为 1 次（判空+上限共用） |
| 5 | `_collection` | 加固 | `existing.metadata` 为 `None` 时 `.get()` 抛 AttributeError → `(metadata or {})` 防御 |
| 6 | `_query_variants` | 文档纠偏 | docstring 「去标点版」与实际行为（去引号主干）不符 → 修正 |

### 8.4 契约不一致与跨模块上报（不擅动，待统筹裁决）
