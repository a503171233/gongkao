# B8 · 输出校验模块（网站二 内核）

## 1. 目标

幻觉检测三道关卡：引用一致性、关键事实（数字）校验、超纲反查；提供拦截计数与统计，供监控看板。

## 2. 现状

`backend/poc/guard.py`：`run_guard`、`_check_reference`/`_check_facts`/`_check_scope`、`GuardCounter`、`guard_counter`。

## 3. 函数契约（`02` §6.3）

```
run_guard(answer, hits, tcfg, teacher_id) -> (passed:bool, detail:{fails:[...],checked:[...]})
reason ∈ {reference, fact, out_of_scope}
```

## 4. 三关卡规则

| 关卡      | reason         | 规则                                                               |
| ------- | -------------- | ---------------------------------------------------------------- |
| 1 引用一致性 | `reference`    | 答案与任一片段有 ≥1 公共 4-gram（跳过通用 gram）                                 |
| 2 事实校验  | `fact`         | 答案中所有数字（**含中文数字**「百分之九十九点七」转阿拉伯）必须出现在片段全文                        |
| 3 超纲反查  | `out_of_scope` | 长度≥10 的断言句 embedding 反查 KB，最高相似 < 0.28 拦截；selftest/空库/向量化失败 → 通过 |

## 5. 功能点清单

1. 中文数字识别：`零一二三四五六七八九十百千万` + 点小数；只认长度≥2 或含单位者（防把「一个」误判）。
2. n-gram 过滤：含标点/空白/数字的 gram 跳过；预置 `_SKIP_GRAMS` 通用语跳过。
3. 反查优化：只查长句，多句批量向量查询，减少 embedding 成本。
4. 计数：`GuardCounter` 线程安全，`record(teacher_id, query, reason)`，`stats()` 输出 `total/by_teacher/by_reason`。
5. 最近日志：`recent(limit)` 供看板（C3 复用）。

## 6. 允许修改文件

- `backend/poc/guard.py`

## 7. 验收标准

- [ ] 数字编造（含中文数字）被 `fact` 拦截

- [ ] 无引用大段答案被 `reference` 拦截

- [ ] 明显超纲长句被 `out_of_scope` 拦截（真实 embedding 下）

- [ ] 正常回答不误拦（黄金集回归通过）

- [ ] `/guard/stats` 计数正确

## 8. 坑与注意事项

- `out_of_scope` 阈值 0.28 是实测平衡值，调整需黄金集回归验证。

- selftest 哈希向量无语义，`out_of_scope` 必须直接通过，否则自测全红。

- 守卫必须返回原因枚举，供前端 A5 做中文映射，勿改枚举字符串。

## 10. v2 分级拦截（2026-09-05 交付）

> 背景：v1 一刀切（任一关卡失败 → 整体拒答）误杀合理助教表达（序数、列表编号、算式、
> 同义改写、口语鼓励），不符合教学答疑场景。v2 改为**四级判定 + 三级可配置策略**。
> 涉及文件：`guard.py`（核心引擎）/ `answer.py`（分级接入）/ `api.py`（guard\_warn 转发）/
> `config.py`+`admin.py`（guard\_config 列）/ 前端 `a3/a4/a5 + share.html`（提示条渲染）。

### 10.1 四级判定

| 级别        | 行为   | 非流式响应                        | 流式事件                       | 缓存               |
| --------- | ---- | ---------------------------- | -------------------------- | ---------------- |
| `pass`    | 放行   | 原样                           | —（正常 refs/done）            | 入缓存              |
| `warn`    | 轻度提醒 | `guard_level`+`guard_notice` | `guard_warn{level,notice}` | 入缓存              |
| `confirm` | 二次确认 | 同上（提示"以讲义为准"）                | 同上                         | **不入缓存**（重问重新生成） |
| `block`   | 硬拦截  | 拒答文案+`guard_fails`           | `guard_block`（终止链路）        | 不入缓存             |

前端渲染：warn=蓝灰提示条 / confirm=橙色提示条（不替换正文）；block=替换为拦截警示（原行为）。

### 10.2 三关卡 v2 判定依据

**关卡1 引用一致性（reference）**：公共 4-gram 数分档

- `≥ ref_strong_hits(3)` → 强引用直过；`1~2` → warn（改写多但确有引用）；`0` → confirm 证据；
  「无引用 + 出现超纲证据」交叉升级为 block（编造实锤）。

**关卡2 关键事实（fact）数字三分类**：

- **关键数字**（后缀`%`、年份`(19|20)\d\d`、量纲后缀`年万亿元倍`、前 6 字窗口含`率/高达/达到/上涨/下跌/增长/下降`、中文`百分之X`/万级）未命中语料 → **block**（真幻觉）；

- **普通数字**未命中 `> fact_max_miss(0)` → confirm；`≥ fact_block_miss(3)` → block（数字密度异常）；

- **豁免**（合理助教表达）：① 算式子句（含`=`且≥2数字）与`变量=值`中的数字及其全文复用（计算/推导结果）；② 序数`第N`；③ 列表编号（行首/空白/冒号/逗号/句号后 + `.` `、` `）`等编号符）；④ 括号编号`（N）`；⑤ **问题原文数字回声**（复述用户输入不算编造）；⑥ 中文万级换算形（答案"十二万"↔语料"12万"）；⑦ 量词歧义（千万/百万…，v1 已有）。

**关卡3 超纲反查（out\_of\_scope）断言句占比分档**（v1 为"单句低于阈值即拦"）：

- 占比 `> scope_block_ratio(0.70)` → block；`> scope_confirm_ratio(0.50)` → confirm；`> scope_pass_ratio(0.30)` → warn；

- **不参与反查的句子**：设问句（？结尾，课堂互动）、<10 字短句、≤40 字引导互动句（咱们/你注意/接下来/举个例子/加油… 开头）；

- **小样本保护**：断言句数 `< scope_min_sentences(3)` 时比例不可靠——全超纲才 block，否则封顶 confirm（防单句误杀）；

- selftest/空库/向量化失败 → 跳过（v1 契约不变）。

### 10.3 策略三级叠加（后写覆盖前写）

| 层级      | 来源                                                 | 典型差异                                                                |
| ------- | -------------------------------------------------- | ------------------------------------------------------------------- |
| ① 学科预设  | `teacher_subject` 命中关键词                            | 数量关系/资料分析：数字关最严（fact\_max\_miss=0）；常识/时政/申论：超纲容忍放宽（block 0.80）      |
| ② 场景覆盖  | `detect_scene(query)`：chat/problem/concept/general | chat：引用要求最低+超纲反查结构性跳过；problem：超纲档放宽（解题推导句式发散）；concept：超纲档收紧（定义须贴讲义） |
| ③ 老师级覆盖 | `teachers.guard_config` JSON 列（admin API 可写）       | 最高优先级，逐字段覆盖；置空回退预设                                                  |

### 10.4 可调参数与取值范围（`guard.POLICY_FIELDS`）

| 参数                    | 默认   | 范围           | 说明                     |
| --------------------- | ---- | ------------ | ---------------------- |
| `ref_strong_hits`     | 3    | \[1,10]      | 强引用 4-gram 门槛          |
| `fact_max_miss`       | 0    | \[0,5]       | 普通数字允许未命中数（超出→confirm） |
| `fact_block_miss`     | 3    | \[1,10]      | 普通数字未命中≥此值→block       |
| `scope_sim_threshold` | 0.28 | \[0.10,0.50] | 单句超纲判定阈值（v1 实测平衡值）     |
| `scope_pass_ratio`    | 0.30 | \[0,1]       | 超纲占比通过线                |
| `scope_confirm_ratio` | 0.50 | \[0,1]       | 超纲占比确认线                |
| `scope_block_ratio`   | 0.70 | \[0,1]       | 超纲占比拦截线（三档须严格递增）       |
| `scope_min_sentences` | 3    | \[1,10]      | 小样本保护下限                |

配置方式：`PUT /admin/teachers/{id}`（body 含 `guard_config` JSON 对象；admin 校验字段白名单+范围+三档递增）。
运行时即时生效（reload\_teachers 热加载），空值/非法 JSON 自动回退学科预设（不炸主链路）。

- SSE 新增 `guard_warn` 事件（a4 分发表已注册）；`guard_block` 事件/时序不变。
