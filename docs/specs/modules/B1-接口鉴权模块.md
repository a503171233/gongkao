# B1 · 接口鉴权模块（网站二 内核）

## 1. 目标

FastAPI 入口层：路由注册、请求模型（Pydantic）、鉴权与额度守卫、SSE 流包装、CORS/监控中间件。是前端（A 系列）与内核各模块（B2-B8）的唯一接缝。

## 2. 现状

`backend/poc/api.py` 全部路由已实现（见 `02-数据契约.md` §3）。本模块负责维护路由层，其余 B 模块只提供纯函数/类，不直接沾 FastAPI。

## 3. 关键内部职责

| 项 | 位置 | 说明 |
|---|---|---|
| 请求模型 | `AskReq/RegisterReq/LoginReq` | 校验入参 |
| 鉴权解析 | `_resolve_user(authorization)` | Bearer → user dict；无 token 返回 None（匿名） |
| 额度守卫 | `_quota_guard(user)` | 登录用户查 `check_quota`，超限 429；匿名放行 |
| 老师校验 | `_check_teacher(teacher_id)` | 不存在 → 404 |
| SSE 打包 | `_sse(event, data)` | `event:`/`data:` 协议 |
| 指标中间件 | `http_metrics` | 全链路 method/path/status/latency |
| 会话编排 | ask 内的解析/创建/取历史/落库 | 见 §4 |

## 4. /ask 主流程（必须保持的时序）

```
解析 session_id（不存在或跨老师 → 重建）
取历史(存 user 消息前)
存 user 消息
rag_ask(...) 推理
consume(额度)
分支：流式(SSE 事件流，finally 落 assistant) / 非流式(直接落 assistant)
```

## 5. 允许修改文件

- `backend/poc/api.py`

## 6. 验收标准

- [ ] 全部路由 curl 均返回契约文档约定字段（`02` §3）
- [ ] 无 `teacher_id` 传错时 404；额度用完 429；上传无 secret 403
- [ ] 流式 `start/delta/refs/done` 顺序正确，`guard_block` 时不落 assistant 为正常回复
- [ ] 匿名、登录、OAuth 三种身份下的会话归属正确
- [ ] `/metrics`、`/metrics/prometheus`、`/guard/stats` 可访问

## 7. 坑与注意事项

- **路由前缀**：nginx 剥 `/api`，后端路由不含 `/api`；Gitee 回调对外带 `/api`。
- **SSE finally 落库**：流式中途失败也要保住 user 消息；assistant 落库需 try 包裹防炸断推送。
- **额度消耗时机**：只在推理成功后 `consume`；警惕重复扣费。
- 本模块是集成点，新增路由须同步更新 `02-数据契约.md` 并由统筹确认。
