# C4 · 学员增值功能（扩展业务域）

## 1. 目标

增加学员留存类功能：学习记录、错题/收藏、真题练习。复用问答与会话能力，形成「学-练-错-复习」闭环。

## 2. 现状

仅有多轮会话（`chat.db`），无错题/收藏/练习概念。

## 3. 变更提案（需确认后写入 `02`）

### 3.1 新表（`chat.db` 或新 `study.db`）

| 表 | 字段 |
|---|---|
| favorites | id PK, user_id, teacher_id, question, answer, refs, created_at |
| mistakes | id PK, user_id, teacher_id, question, user_answer, correct_note, created_at |
| practice_log | id PK, user_id, teacher_id, question, answer, score, created_at |

### 3.2 新接口（需 Bearer，匿名只读练习）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/favorites` | 收藏当前问答 |
| GET | `/api/favorites` | 我的收藏列表 |
| DELETE | `/api/favorites/{id}` | 取消收藏 |
| POST | `/api/mistakes` | 记录错题 |
| GET | `/api/mistakes` | 错题本 |
| GET | `/api/practice/next?teacher_id=` | 抽一道题（从知识库出题或预置题库） |
| POST | `/api/practice/submit` | 提交练习答案并评分 |

## 4. 功能点清单

1. 收藏入口：A5 渲染区加「收藏」按钮 → 调接口 → toast 反馈。
2. 错题本：记录答错题 + 正确讲解，支持复习会话跳转。
3. 真题练习：从知识库/预置题库出题（无真实题库时可先「随机抽取知识点提问」兜底），提交后由 B 系列回答/评分。
4. 会员权益联动（可选）：收藏/错题上限 free 限 50 条、member 不限（与 C1 联动）。

## 5. 允许修改文件

- 新建 `backend/poc/study.py`
- `backend/poc/api.py` 新增 `/favorites`、`/mistakes`、`/practice/*`
- `frontend/js/a5-render.js` 增收藏按钮；`frontend/js/a3-session.js` 可增入口

## 6. 验收标准

- [ ] 收藏/取消/列表正常，归属当前 user
- [ ] 错题记录与讲解恢复正确
- [ ] 练习能出题并提交评分
- [ ] 匿名用户不写库（或明确提示登录），资深权益上限生效（如启用）

## 7. 坑与注意事项

- 收藏/错题含 `refs` 时，最好存快照而非动态查库（知识库可能更新）。
- 练习评分依赖 B 系列回答质量，无真实题库时不要给错误答案标「正确」。

### 8.4 关键设计决策

1. **快照存储**：收藏/错题的 refs 存为 JSON 字符串，避免知识库更新后引用失效。
2. **惰性到期**：练习评分若无法确定对错，score 设为 -1 表示"待老师讲解"，不虚假标注。
3. **用户隔离**：所有查询强制按 user_id 过滤，不同用户数据互不可见。
4. **匿名只读**：匿名用户可获取练习题（只读），但收藏/错题/提交需登录。
5. **练习兜底**：无预置题库时，从 Chroma 向量库检索知识点作为练习题源。
