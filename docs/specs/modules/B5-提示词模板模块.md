# B5 · 提示词模板模块（网站二 内核）

## 1. 目标

维护教师人设 System 模板与拒答话术、固定解题步骤格式、引用来源话术约定。保证所有老师回答风格统一、可复刻课堂口语。

## 2. 现状

`backend/poc/answer.py`：`SYSTEM_TEMPLATE`、`REJECT_TEXT` 常量，`build_context`/`build_messages` 中的模板 `format` 占位。

## 3. 模板占位契约

`SYSTEM_TEMPLATE.format()` 入参（由 B6 填）：

| 占位 | 含义 |
|---|---|
| `{teacher_name}` | 老师名（如 星辰老师） |
| `{teacher_subject}` | 科目（如 言语理解） |
| `{reject}` | 拒答话术（`REJECT_TEXT`） |
| `{context}` | 检索上下文（`build_context` 输出） |
| `{doc_hint}` | 来源文档名提示 |

**固定规则**（模板内已含，不可删）：
1. 严格依据【教学资料】，禁止编造
2. 讲题步骤：做题思路 → 题干拆解 → 选项分析 → 易错点提醒
3. 复刻老师课堂口语，禁止机器话术
4. 引用出处自然带文档名
5. 无资料直接输出 `{reject}`

## 4. 功能点清单

1. 人设定制：不同老师差异化（`teacher_name`/`teacher_subject`）。
2. 拒答话术 `REJECT_TEXT`：统一为「该知识点XX老师暂未录入资料库，请勿自行拓展…」。
3. 行文规范：讲题完整展开、概念解释简明；篇幅控制由模板引导 + `max_tokens` 兜底。

## 5. 允许修改文件

- `backend/poc/answer.py` 中模板常量区（`SYSTEM_TEMPLATE`/`REJECT_TEXT`）
- 若模板变长，可抽到 `backend/poc/prompt.py`（需同步 B6 引用）

## 6. 验收标准

- [ ] 模板占位齐全，`format` 不抛 KeyError
- [ ] 拒答话术与 `REJECT_TEXT` 一致
- [ ] 老师人设/科目正确注入
- [ ] 引用来源话术自然（讲义名出现）

## 7. 坑与注意事项

- 改动模板会直接影响所有老师回答质量，需跑黄金集回归（`docs/测试清单.md`）。
- 模板禁止引入会触发 B8 误拦的表述（如无必要数字、无来源断言）。

### 8.3 老师差异化点（本次新增/调整）

1. **人设强化**：由「解题方法论专家」升级为「资深讲师 + 熟悉考生常见误区与高频失分点」，注入不同老师名/科目后，身份段自然差异化（实测：星辰老师/言语理解 与 云舟老师/逻辑判断 两套人设均正确渲染）。
2. **口语化具象化**：新增课堂用语示例「咱们」「你注意」「这里要看清」，替代抽象的「通俗易懂」，让 LLM 输出更接近老师课堂口吻；禁止项由「生硬机器话术」扩展为「书面腔、机器话术、条款式罗列」。
3. **拒答纪律收紧**：由「直接回复」升级为「**直接原样输出，不要解释、不要补充**」，防止 LLM 在无资料时自行发挥加戏。
4. **引用话术自然化**：示例由「我们讲义《X》里讲过」改为「咱们讲义《X》里讲过」，并要求「不标注页码、不凭空编造出处」。

### 8.5 上报事项（只上报，未擅动契约）

- `REJECT_TEXT` 中的 `XX老师` 是**字面占位符**而非 `{teacher_name}` 可格式化占位：该常量在 `_gen_reject()`（流式拒答）与 `ask()`（非流式拒答）中被**原样输出、不经 `.format()`**，若改成 `{teacher_name}` 模板会导致线上吐字面 `{...}`。动态老师名需改调用点，超出 B5 权限范围 → **建议维持现状**，由统筹评估是否在 B4/B1 侧做格式化改造。
