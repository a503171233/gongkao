# A5 · 结果渲染模块（网站一 前端）

## 1. 目标

渲染问答结果：流式增量显示、引用来源展示、幻觉拦截提示（`guard_block`）、拒答话术展示、历史消息回放渲染。负责视觉呈现，不含请求逻辑。

## 2. 现状

`frontend/index.html` 流式区：`delta` 增量拼接、`refs` 引用列表、`guard_block` 拦截提示替换已显示文本、拒答文案展示。

## 3. 输入来源（由 A4 回调 / A3 传入）

| 事件/输入 | 处理 |
|---|---|
| `start` | 新建回答气泡，准备增量容器 |
| `delta` | 追加文本片段（增量渲染，不整段重绘） |
| `refs` | 渲染引用列表（doc_name + score） |
| `done` | 标记完成，停止 loading 态 |
| `guard_block` | 将当前回答替换为拦截提示（不再追加内容）；展示 `fails` 对应原因 |
| `error` | 展示错误提示 |
| 历史消息数组 | 按 role 渲染 user/assistant 气泡 |

## 4. 功能点清单

1. 增量渲染：`delta` 文本逐段 append，避免整段重绘导致闪烁。
2. 引用展示：`refs` 列表（`doc_name`、`score` 取 3 位小数），无引用时隐藏。
3. 拦截提示：收到 `guard_block` 时，用提示文案替换当前气泡；`reason` 映射为用户可读中文（`reference`=引用不符 / `fact`=数字不符 / `out_of_scope`=超纲）。
4. 拒答展示：`answer` 为拒答话术时按正常文本渲染（可加样式区分）。
5. 滚动：新内容自动滚动到底部。
6. 历史回放：A3 传回历史消息时，按正序渲染气泡，不重复请求。

## 5. 模块内契约

- **文件**：`frontend/js/a5-render.js`。
- **提供**：`A5.appendDelta(text)`、`A5.showRefs(refs)`、`A5.finish()`、`A5.block(reason)`、`A5.renderHistory(messages)`。
- **订阅**：既可由 A4 的 `GK.sse` 回调直接调用，也可通过 `GK.bus` 事件解耦（建议用回调直连，减少事件噪声）。

## 6. 允许修改文件

- `frontend/js/a5-render.js`（新建）
- `frontend/index.html` 结果渲染区容器

## 7. 验收标准

- [ ] 流式输出逐段显示，无整段重绘闪烁
- [ ] `refs` 正确显示来源文档与分数
- [ ] `guard_block` 出现时回答被替换为拦截提示，且不再追加 delta
- [ ] 拒答话术正常显示
- [ ] 切换会话/老师能清空渲染区并回放正确历史

## 8. 坑与注意事项

- `guard_block` 后后端不再发 `refs`/`done`，A5 必须能独立结束渲染态。
- 拦截原因中文映射与 `guard.py` 的 `fails` 枚举保持一致（`reference/fact/out_of_scope`）。
