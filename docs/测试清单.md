## 三、前端结构检查（改 index.html 后必跑）

每次改 `frontend/index.html` 后，用一次性 Python 脚本做结构检查（写临时脚本跑完即删）：
- `div` 配对计数一致
- `id` 无重复
- `<script>`/`</script>` 配对
- 关键元素/JS 函数存在（authArea/authModal/renderAuthArea/parseSSE/guard_block/uploadBtn/sessionList 等）
- 既有功能锚点未破坏（giteeLoginBtn、newSessionBtn、uploadBtn、sessionList、parseSSE、guard_block）

示例检查脚本模式：
```python
html = open(r"D:\xiangmu\gongkao\frontend\index.html", encoding="utf-8").read()
assert html.count("<div") == html.count("</div>")
import re
ids = re.findall(r'id="([^"]+)"', html)
assert len(ids) == len(set(ids)), "重复 id!"
for k in ["authModal", "renderAuthArea", "parseSSE", "guard_block", "giteeLoginBtn"]:
    assert k in html, f"缺少 {k}"
print("HTML 结构 OK")
```

## 六、测试隔离约定

- 所有测试用 `tempfile.mkdtemp` 隔离，`os.environ["CHAT_DB"/"AUTH_DB"/"DATA_DIR"/...]` 指向临时目录
- 测试前 `os.environ.pop("GITEE_CLIENT_ID", None)` 保证 Gitee 走降级路径
- `EMBED_PROVIDER=selftest` 时 guard 超纲反查自动跳过（哈希向量无语义）
- 跑测试不需要真实 API key（answer 走 mock/selftest）
