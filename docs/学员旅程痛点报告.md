# 学员旅程痛点报告（浏览器实地走查）

> 走查方式：playwright 无痕浏览器模拟新学员完整旅程——首页 → 注册 → 提问 → 练习 → 组卷 → 错题本 → 报告 → 激励 → 导出 → 论坛 → 会员。
> 走查账号：`walker01`（新注册）；截图存于 `.walkthrough/`（沙箱）。
> 每项痛点均已在代码/接口层验证根因，标注了修复定位。

---

## 一、P0 / P1：核心链路缺陷（建议优先修复）

### 1. 匿名会话池全局共享，访客提问相互可见
- **现象**：全新无痕浏览器打开学习中心，侧栏直接显示陌生访客的历史提问（如「转折关系做题的核心口诀是什么」），且可点开查看完整内容。
- **验证**：无 token `GET /api/sessions` 返回所有 `user_id=anonymous` 的会话；`GET /api/sessions/{id}/messages` 匿名可读匿名会话全文。**登录用户的会话防护有效**（匿名读返回 403，已实测），泄漏面仅限未登录访客群体。
- **根因**：`api.py` `_session_owner_guard` 设计为「匿名会话公开可读」，所有未登录访客共享 `anonymous` 身份。
- **影响**：学员未登录时试探性提问（常见行为）会被后来的陌生访客看到，隐私边界与预期不符；侧栏出现陌生人会话造成「数据错乱」观感。
- **修复方向**：匿名会话不进历史列表（仅保留当前会话上下文），或按浏览器指纹隔离匿名身份。

### 2. 核心问答 500，错误文案暴露内部运维信息
- **现象**：注册后第一件事提问 → 「⚠️ 问答失败: 未配置 API_KEY：请在 .env 填入中转站 key (HTTP 500)」。
- **根因**：沙箱未配置 LLM key（环境问题，生产需配好）；但**前端把后端 detail 原样展示**，运维信息（.env、中转站）不应出现在学员界面。
- **修复方向**：后端对 5xx 统一返回脱敏文案（「老师繁忙，请稍后再试」）；前端对非 4xx 错误统一兜底文案。另：本次失败提问未扣每日额度（实测仍为 20），额度逻辑正确。

### 3. 题库按 teacher_id 隔离，T002（逻辑判断老师）名下 0 题
- **现象**：切到云舟老师 → 练习分类下拉只剩「全部分类」；抽题返回的是**言语理解**演示题（学科错乱）；组卷无题可用。
- **验证**：`GET /api/practice/categories?teacher_id=T002` 返回 `{"categories":[]}`；`/practice/next?teacher_id=T002` fallback 到 knowledge_point 演示题。447 道真题全部挂在 T001 名下（采集时的挂载惯例）。
- **根因**：题库查询处处带 `teacher_id` 过滤，而公考真题本质是全局资源，按老师隔离把题库切碎。
- **修复方向**（二选一）：① 练习/组卷/模考的题目查询去掉 teacher_id 维度（推荐，分类已够用）；② 数据层把题库复制挂到 T002（不推荐，数据冗余）。

### 4. 练习答错后看不到解析（组卷却能看到，同源不同权）
- **现象**：练习答错仅显示「✗ 回答错误｜正确答案：D」，想知道为什么错必须跑去错题本。图推题更糟——「正确答案 D」还得回题干图里找 D 是哪个。
- **根因**：`study.py` `submit_practice()` 中解析 `q['analysis']` 只写进错题本，`feedback` 仅返回「回答错误，正确答案：X」；而组卷判分路径把 analysis 完整渲染（实测组卷结果页解析完整）。
- **修复方向**：`submit_practice` 响应增加 `analysis` 字段，前端练习反馈区追加「📖 解析」区块；同时把粉笔解析原文残留的「[图]」占位清理。

### 5. 解析配图未采集，解析文字自相矛盾
- **现象**：错题本解析写着「如下图所示…[图] 解法二…」，但「[图]」处无图（字面量残留）。题干图正常（3/3 渲染成功），唯独解析图缺失。
- **根因**：批次9.2 图片化只处理了**题干 HTML** 的 `<img>`；`analysis` 字段里粉笔原文的解析配图未下载，只留下「[图]」文字占位（DB 实证：analysis 无 `<img>` 亦无 `![图N]`）。
- **影响**：空间重构/图形推理类解析高度依赖配图，缺图后解析可读性大幅下降。
- **修复方向**：采集器扩展处理 analysis 的图片下载（复用 `_download_imgs`），存量 17 道图推题重跑解析回填。

## 三、走查中验证通过的功能（无痛点）

- **注册/登录**：5 位密码正确拦截「密码至少 6 位」；注册即登录无缝进入学习态。
- **练习主流程**：抽题、选项交互、判分、错题自动入库全通；题干图片（含资料分析图表、图推题组图）渲染成功，`/api/qimg` 链路稳定。
- **错题本**：解析文字完整、题干图渲染、重练/已掌握操作齐备。
- **组卷全流程**：条件组卷 → 整卷作答 → 自动判分 → 完整逐空解析展示。
- **学习报告**：练习/组卷数据实时汇总（分类正确率、错题数、复习队列）。
- **激励系统**：答题即得积分（9 分/青铜 Lv1）、成就「初出茅庐」自动解锁。
- **DOCX 导出**：端到端通过——学习报告导出 37KB/41 段，python-docx 回读正常。
- **论坛**：空态引导友好（「来发第一帖吧」）、分类/排序/登录态正确。
- **会员付费**：三档价格弹窗（¥29/79/299）+ 充值码激活入口正常。

## 四、建议修复顺序

1. **#2 错误文案脱敏 + 生产环境配置 LLM key**（影响：所有新用户第一印象）
2. **#3 题库去 teacher_id 隔离**（影响：T002 全部练习场景，一行查询改动收益最大）
3. **#4 练习反馈补解析**（学习闭环核心，后端 +前端各一处小改）
4. **#1 匿名会话隔离**（隐私边界）
5. **#5 解析图采集**（涉及重采，可与图推题回填合并做）
6. P2 按序小批量清理（#8/#9/#10 均为一处改动）
